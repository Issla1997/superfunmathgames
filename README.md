# superfunmathgames

A locally bundled browser-game arcade. The name is branding only: the catalogue is intended to include many genres, not only maths games.

## Project status

Initial repository setup. The playable catalogue and website are being built.

## Requirements

- Games run locally in the application; no iframe embeds or remote game-site dependencies.
- Prefer original game implementations and redistributable assets.
- Every catalogue entry must represent a genuinely playable game.
- Keep credits and license information accurate for all third-party assets and code.
